# TRADE MONITOR

タブレット（横画面）で登録銘柄の株価・チャートを自動切替表示する静的 Web アプリです。GitHub Pages でそのまま公開できます。ビルドは不要です。

## 公開手順（GitHub Pages）

1. このフォルダの中身をリポジトリのルートに置いて push します。
2. GitHub のリポジトリで **Settings → Pages → Build and deployment** を開き、Source に「Deploy from a branch」、Branch に `main` / `/ (root)` を選びます。
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPad の Safari で開き、「共有 → ホーム画面に追加」を選ぶと全画面で起動できます。

## チャートデータの取得について

Yahoo Finance の API はブラウザから直接呼び出せない（CORS 制限）ため、中継経路を通して取得します。取得の流れは次のとおりです。

- **経路を複数持つ**：`r.jina.ai` を主な経路にし、allorigins と codetabs を予備にしています。成功率の高い経路から順に使います。4秒以内に応答がなければ別の経路も同時に試し、失敗した経路はしばらく休ませます。Yahoo の窓口（query1 / query2）も交互に使います。
- **通信量を減らす**：日足10年分を最初に1回だけ取得し、週足と月足はアプリ内で計算します。2回目からは直近1か月分だけを取得して継ぎ足します。
- **裏で先回りして取得する**：まだデータの無い銘柄を8秒に1件ずつ取得します。すべて取得し終えたら、場中に「この先表示する3銘柄」のうち10分以上古いものだけを更新します。全銘柄を回し続けることはしません。
- **継ぎ足しは小さく**：2回目以降の更新は直近5日分（約1KB）だけを取得します。
- **通信状況の確認**：画面上部の「最終通信」をタップすると、直近1分と今日の通信回数、これからの取得予定、最近の通信履歴（時刻・銘柄・内容・経路・結果）を確認できます。
- **保存済みのデータは必ず表示する**：保存済みのデータは古くても先に表示し、裏で最新のデータに入れ替えます。通信に失敗しても画面は空になりません。
- 東証のデータは約20分遅れです。銘柄名の右上には、そのデータが何時点のものかを表示します。
- URL の末尾に `?demo` を付けて開くと、通信せずにダミーデータで画面を確認できます（動作確認用）。

## 設計書との対応

| 設計書 | 実装 |
|---|---|
| 2画面構成・ハンバーガーで遷移、遷移中は巡回停止 | 設定を開いている間はタイマー停止。「保存して戻る」と「×」のどちらでも保存して再開 |
| 日本式の騰落色（上昇=赤） | 既定は上昇=赤。設定で米国式（上昇=緑）に切替可 |
| 画面タッチ中は巡回を一時停止 | チャートを操作すると、最後の操作から10秒間は巡回を停止 |
| 4.1 事前取得 | 切替の N 秒前（既定15秒・設定で変更可）に次の銘柄を取得 |
| 4.1 キャッシュ・重複防止 | キャッシュ有効期間は1〜3分。同じ銘柄への同時リクエストは1本にまとめる。前/次を連打したときは350ms後にだけ通信 |
| 4.1 チラつき防止 | 表示レイヤーを2枚重ね、裏側で描画を終えてから表示を切り替える |
| 4.2 時間外 | 引け後（+20分の遅延分）に取得済みならAPIを呼ばずにキャッシュを表示。昼休みも同じ扱い |
| 4.3 永続化 | 銘柄リスト・設定・株価は LocalStorage、チャートデータは IndexedDB。再起動直後からキャッシュを表示 |
| 4.3 エラー時 | アプリは止めずにステータスバーに表示し、前回データを維持。次の巡回時に再取得 |

補足

- 足種は5分足・日足・週足・月足から選べます（既定は左が日足、右が月足）。テクニカル指標は移動平均線（日足5/25、週足13/26、月足12/24）、ボリンジャーバンド（20, 2σ）、出来高です。
- 東証・米国市場の休場日（米国は短縮取引日も）は `js/holidays.js` に2025〜2040年分を登録しています。`python3 tools/gen-holidays.py` で作り直せます。将来分は祝日法・取引所の規則から計算した予定日なので、変更があれば作り直してください。
- 銘柄名で検索するとき、主要約60銘柄は内蔵の日本語辞書で探し、それ以外は Yahoo の検索 API で探します。Yahoo は英語名を返すため、表示名は登録時や一覧の銘柄名タップで変更できます。
- 一括インポートは設計書のとおり設けていません。
- キーボード操作：← / → で前/次、Space で一時停止/再生。

## 銘柄の登録と銘柄名辞書

- 登録できるのは最大999銘柄です。登録数が増えても通信量は増えません。裏での先回り取得は一定の間隔で1件ずつ行い、1分あたりの通信回数にも上限があるためです。そのぶん、登録数が多いと1銘柄あたりの更新間隔が長くなります。
- 日本株は4桁のコード（例: `7203`, `130A`）、米国株はティッカー（例: `AAPL`, `BRK-B`）で登録します。銘柄名での検索（ひらがな・カタカナどちらでも可）にも対応しています。
- 日本株の銘柄名は `data/jp-stocks.json`（JPX 公表の東証上場銘柄一覧、2026年10月末時点で4,444銘柄）を使います。新規上場銘柄を反映するには、月1回程度 `python3 tools/update-jp-stocks.py` を実行して push してください。辞書にない銘柄は Yahoo の検索で探します。
- 米国株は S&P500・ナスダック100 の主要銘柄、人気の ETF、主な ADR など約670銘柄について日本語名を内蔵しています。それ以外は英語名で表示します。米国市場の取引時間（米国東部時間 9:30〜16:00、夏時間は自動判定）に合わせて更新を制御します。米国の祝日・短縮取引日（13:00 終了）にも対応しています。

## 通信量の上限（アクセス制限を受けないための対策）

- チャートの描画には TradingView 社のライブラリ（Lightweight Charts）を使っています。アプリに同梱しているので、TradingView のサーバーには一切アクセスしません。
- 株価データは Yahoo Finance から中継経路を通して取得します。取得は次のように制限しています。
  - 同時に通信するのは2本まで、通信を始める間隔は1.5秒以上です。
  - 1分間に始める通信は12回までです。そのうち裏での先回り取得は8回までです。
  - 「回数制限」の応答を受けたら、その経路を90秒、全体を15秒止めます。
  - 失敗が続く銘柄は、2分・4分・8分…と間隔を空けてから再試行します（最長30分）。
  - 閉場中は、引け後のデータを取得済みなら通信しません。

## 公開時の手順

更新したら `python3 tools/bump-version.py` を実行してから push します。読み込むファイルに版番号が付くので、端末に古い版が残らず、開いたままの端末も15分以内に自動で新しい版に切り替わります。

## 通信回数（1日300回まで）

- **まとめて取得**：この先表示される最大20銘柄を、1回の通信でまとめて更新します（2分に1回まで）。登録数が増えても回数はほぼ一定で、場中は1日約165回です。
- **当日の始値**：まとめて取得では取れないため、その日初めて表示する銘柄だけ1回個別に取得します。表示対象が100銘柄を超えると、最初の1分の値で近似して（20銘柄まとめて1回）この通信も省きます。そのときは画面上部に「始値は近似」と小さく表示します。
- **新規登録**：登録した直後にすぐ取得します。以前のデータが残っている銘柄は、足りない直近分だけを取ります。
- **上限**：1日（日本時間0時区切り）300回を超えません。裏での初回読み込みは240回までとし、表示用に60回を残します。上限に達したら、翌日0時まで保存済みのデータで表示し、画面上部に「本日の通信上限」と表示します。

## データの保存場所と容量の管理

| 保存先 | 内容 | 大きさの目安 |
|---|---|---|
| ブラウザの IndexedDB（端末内） | 銘柄ごとのチャートデータ（日足約2年・週足・月足10年） | 1銘柄 数十KB |
| ブラウザの localStorage（端末内） | 銘柄リスト・設定・通信回数 | 数KB〜数十KB |
| メモリ | 最近表示した最大60銘柄分だけ | — |

- 保存データは端末の中だけにあり、どこにも送信しません。中身は公開されている株価と、登録した銘柄リストだけです。
- **自動の掃除（起動時と1日1回）**：登録から外して30日たった銘柄、3日以上更新していない5分足、旧版の形式のデータを削除します。
- **いっぱいになったとき**：登録から外した銘柄をすぐ削除し、それでも足りなければ古いものから削除します。保存できなくても、メモリ上のデータで表示は続きます。
- 「通信状況」画面で、保存データの大きさと件数を確認できます。

## 安全対策

- 読み込めるファイルはこのサイトのものだけ、通信できるのは株価の中継先とこのサイトだけに制限しています（Content-Security-Policy）。
- 外部への通信に、このページの URL（参照元）を付けません。
- 表示名などの文字は HTML として解釈しないので、細工された名前を貼り付けても、スクリプトとして実行されることはありません。
- 保存データや「貼り付けて復元」で読み込んだデータは、決められた項目・形式だけを取り出して使います。壊れたデータや想定外の値が混じっていても、不具合の原因になりません。
